This is the first coffee-shop packet.

It exists to make the book real enough to sit with: a door in the fog, a
working voice, a chapter spine, and enough living material to reveal where the
book is alive and where it is faking.

The packet is intentionally dated. The repo keeps the stable version label
`reader-v0`; the generated file carries `260707` so a printed copy can be
placed on the timeline without turning every draft into a new historical shard.

## Operating Rule

Read this copy with three pens if possible:

- one for what is alive;
- one for what is false, coy, evasive, or too easy;
- one for what should become a chapter, score, diagram, scene, or build task.

If a sentence sounds like it is trying to recruit, flatten, mystify, therapize,
or win the argument early, wound it in the margin.

If a sentence helps a life become more available to itself, keep it alive.
