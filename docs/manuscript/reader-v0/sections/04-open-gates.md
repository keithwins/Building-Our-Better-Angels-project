# Open Gates

This packet is allowed to exist before the gates are closed. It is not allowed
to forget that they are open.

## Gate 1: Public/Private Seam (`oq-001`)

The book needs a practical doctrine for what can move into public prose from:

- the Walk;
- the Fog stream;
- Drive;
- the local corpus;
- Salon;
- Asterisms;
- GitHub;
- session records;
- private conversations.

The doctrine does not need to be perfect before Keith prints this copy. It does
need to exist before the book is handed outward as a trusted-reader artifact.

The rule should probably distinguish at least:

- public source;
- private source used only for synthesis;
- private source quotable with explicit consent;
- private source that may shape the work but must not be exposed;
- sensitive source that requires omission, local-only treatment, or
  confidential-class access control (not “forgetting” — see Gate 2).

## Gate 2: No Forgetting (`oq-009`) — CLOSED 2026-07-10

**Adopted:** [`docs/core/no-forgetting.md`](../../core/no-forgetting.md).

No forgetting path on the durable substrate. No crypto-shred. No
key-fading-to-oblivion. “Shrouding” as a euphemism for forgetting is retired.
Confidentiality ≠ forgetting. Change of mind = new formations over immutable past.

Reader-v0 may state this as settled doctrine.

## Gate 4: Polyphonic Voice

The book needs a policy for when Keith, Claude, Codex, Opus, Salon, and
Asterisms records appear directly versus when their contributions are absorbed
into the narrator.

Working rule for reader-v0:

- source debts are named in notes and lineage;
- the main voice remains a single book voice unless a direct exchange is doing
  irreplaceable work;
- humor must come from real pressure, not performance;
- disagreement should survive where it clarifies the project.

## Gate 5: The Social Protocol Chapter

The Social Protocol / Interbraid chapter is still underdeveloped. The book
knows it needs the chapter: collaboration requires disclosure, care requires
boundary, and private local braids need ways to coordinate without exposure.

The current packet marks the need but does not yet solve the chapter.

## Print Verdict

Print for Keith: yes.

Hand to trusted outside reader: not yet, unless handed as an explicitly rough
source packet with the gates visible.
