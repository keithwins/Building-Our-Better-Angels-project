# Public / Private Seam

**Adopted 2026-07-10.** Closes `oq-001`.

This is the doctrine for what may move into a **trusted-reader** or **eclosion
public** artifact (book packet, invitation web spine, outward handoff). It does
**not** gate a **Keith-copy** (print, read, mark for yourself).

Companions: [`no-forgetting.md`](no-forgetting.md) (hold ≠ erase),
[`resonator-charter.md`](resonator-charter.md) (self-facing care / pacing).

## Two outward audiences + one inward duty

| Audience | Gate |
|---|---|
| **Keith-copy** | No seam gate beyond enough coherence to use. |
| **Trusted-reader / public invitation** | This seam. Allowlist + membrane enforce it in practice. |
| **Self (inward)** | Do not ambush. Sensitive material may exist in the ledger and still must not be thrown in the face unbidden. **Resonator** owns this duty of care. |

## Five classes

1. **Public source** — may be quoted and named in invitation prose.
2. **Private → synthesis only** — may shape prose; no quotes; no identifiable detail.
3. **Private → quotable with consent** — explicit yes per use (or a standing rule for that stream).
4. **Private → must not be exposed** — may inform the work privately; never enters public prose.
5. **Sensitive / confidential** — access control, local-only, egress stomata.
   Includes (a) material that must not leave the trust boundary, and
   (b) **self-facing sensitivity** (PTSD-class, wounds, anything that should stay
   available but not leap into the room unexpectedly). Class 5(b) is Resonator
   care, not a forgetting path.

## Practical rules

1. **Allowlist is the invitation cut.** If it is not on the public allowlist (or
   an explicit trusted-reader packet manifest), treat it as not public yet.
2. **Membrane before core.** Visitor marks escalate; they do not auto-promote
   into doctrine or the allowlist.
3. **Preserve ≠ publish.** Intake triage fates (`asterisms-only`,
   `defer-eclosion`, etc.) are not publicness rulings by themselves.
4. **Consent is specific.** Class 3 requires a clear yes for that quote/use.
5. **Self-facing pacing is care.** Surfacing class 5(b) material requires
   consent, context, or Resonator judgment under charter — never casual recall
   as “helpfulness.”
6. **No forgetting still holds.** Declining to surface or publish is not
   erasure ([`no-forgetting.md`](no-forgetting.md)).

## What this closes — and what it does not

**Closes:** the open gate that blocked calling reader-v0 / invitation packets
“ready for an outside trusted reader” for want of a seam doctrine.

**Does not close:** Multitude source lineage (Gate 3), polyphonic voice policy
detail (Gate 4), Social Protocol chapter depth (Gate 5), or every future
classification dispute. Those refine under this seam; they are not substitutes
for it.
